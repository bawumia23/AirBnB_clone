# AI: Dynamic Web Lab Generation for Core CSS Concepts

## Overview
This task demonstrates using AI (Claude with Artifacts) to generate 
interactive web development tools for learning CSS concepts.

## Files
- `box_model_lab.html` - Interactive CSS Box Model visualizer with per-side controls
- `flexbox_grid_playground.html` - Flexbox and Grid playground

## AI Tool Used
- **Claude** (Anthropic) with Artifacts feature

## Prompts Used
1. Initial Box Model Lab prompt (basic sliders for padding, margin, border, width, display)
2. Refinement prompt (added side-specific controls and corner radius)
3. Flexbox/Grid Playground prompt (container properties playground)

## How to Use
Open either HTML file in a browser to interact with the visualizers.
